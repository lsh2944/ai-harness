## AWS 읽기 전용 경계 (선택 모듈)

- AWS 조회는 공용 읽기 전용 프로필 `{{AWS_PROFILE}}`로만 한다. MCP(aws-api)를 우선 쓰고 필요하면 CLI(`--profile {{AWS_PROFILE}}`)를 쓴다. 다른 프로필·원시 자격증명·다른 도구로 거부를 우회하지 않는다.
- **AWS 배포·수정·추가·삭제는 사용자만 실행한다.** AI는 로컬 코드·템플릿과 사용자 실행 절차(명령·대상·영향·확인 방법)까지만 준비한다. 구현·테스트·검증 요청도 실환경 변경 승인이 아니다. MCP·CLI·SDK·콘솔/브라우저·원격 명령(SSH/SSM)·CI/CD 트리거를 통한 간접 변경, 실제 데이터 쓰기·업로드·삭제, 메시지 발행·제어 명령, 서비스 시작/중지도 포함하며 test/build/dry-run이라는 이름만으로 안전하다고 판단하지 않는다.
- 인증 갱신은 메인 세션이 대상 환경을 사용자에게 확인하고 MFA 코드를 받은 뒤 `{{ASSUME_ROLE_CMD}} --awsEnv <환경>`으로만 한다(등록된 환경: {{AWS_ENVS}}). 자격증명 파일을 읽어 확인하지 않으며, 비밀값은 조회 가능 여부로만 확인한다.
- 로컬/모의 검증을 먼저 끝낸다. 실환경 검증은 사용자가 실행할 명령·대상·영향·확인 방법과 미검증 상태로 보고하고, 사용자가 제공한 결과와 직접 실행한 결과를 구분한다.
